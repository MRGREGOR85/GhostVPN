<a id="what-is-ghostvpn"></a>

<p><picture><img src="docs/images/g/en-12.svg" alt="WHAT IS GHOSTVPN?" height="41"></picture></p>

```diff
+ GhostVPN hides your real IP address.
```

```diff
+ It connects you to a VPN server or proxy of your choice, and websites
+ see the server's IP instead of yours.
```

```diff
+ You keep your own VPN account (NordVPN, Surfshark, ProtonVPN, Mullvad
+ and many more) or use free servers. GhostVPN replaces all their separate
+ apps with one window: pick a country, click CONNECT VPN, done.
```

<a id="quick-start"></a>

<p><picture><img src="docs/images/g/en-13.svg" alt="QUICK START" height="41"></picture></p>

```diff
+ 1. Download GhostVPN_portable.zip (button above) and unzip it, e.g. to
+ C:\GhostVPN.
+ 2. Run URUCHOM_GHOST.bat and click Yes when Windows asks for
+ administrator rights.
+ 3. Choose a provider in the top-left corner and add servers: SETTINGS →
+ ADVANCED → UPDATE, or SETTINGS → BROWSE CONFIG for your own .ovpn files.
+ 4. Save your VPN login: SETTINGS → VPN ACCOUNT.
+ 5. Pick a country and server, click CONNECT VPN. The map shows your new
+ location.
```

```diff
+ You need: Windows 10/11 · Python 3.10+ (tick Add Python to PATH) ·
+ OpenVPN · administrator rights. Missing Python libraries install
+ themselves on the first start.
```
