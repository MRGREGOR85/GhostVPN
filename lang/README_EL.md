## 👻 Τι είναι το GhostVPN;

### Το GhostVPN κρύβει την πραγματική σου διεύθυνση IP.

Σε συνδέει σε έναν διακομιστή VPN ή proxy της επιλογής σου, και οι ιστότοποι βλέπουν την IP του διακομιστή αντί για τη δική σου.

Κρατάς τον δικό σου λογαριασμό VPN (`NordVPN`, `Surfshark`, `ProtonVPN`, `Mullvad` και πολλούς άλλους) ή χρησιμοποιείς δωρεάν διακομιστές. Το GhostVPN αντικαθιστά όλες τις ξεχωριστές εφαρμογές τους με **ένα παράθυρο**: διάλεξε χώρα, πάτησε **CONNECT VPN**, έτοιμο.

<a id="quick-start"></a>
## 🚀 Γρήγορη εκκίνηση

**1.** **Κατέβασε** το `GhostVPN_portable.zip` από τα [Releases](https://github.com/MRGREGOR85/GhostVPN-BETA/releases/latest) και αποσυμπίεσέ το, π.χ. στο `C:\GhostVPN`.  
**2.** **Εκτέλεσε** το `URUCHOM_GHOST.bat` και πάτησε **Ναι** όταν τα Windows ζητήσουν δικαιώματα διαχειριστή.  
**3.** **Διάλεξε πάροχο** πάνω αριστερά και πρόσθεσε διακομιστές: **SETTINGS → ADVANCED → UPDATE** ή **SETTINGS → BROWSE CONFIG** για δικά σου αρχεία `.ovpn`.  
**4.** **Αποθήκευσε τα στοιχεία σύνδεσης VPN**: **SETTINGS → VPN ACCOUNT**.  
**5.** **Διάλεξε χώρα και διακομιστή**, πάτησε **CONNECT VPN**. Ο χάρτης δείχνει τη νέα σου τοποθεσία.  

**Χρειάζεσαι:** Windows 10/11 · [Python 3.10+](https://www.python.org/downloads/) (τσέκαρε *Add Python to PATH*) · [OpenVPN](https://openvpn.net/community-downloads/) · δικαιώματα διαχειριστή. Οι βιβλιοθήκες Python που λείπουν εγκαθίστανται μόνες τους στην πρώτη εκκίνηση.

### 🆓 Δωρεάν VPN (OpenVPN): χωρίς λογαριασμό, χωρίς πληρωμή

| Πάροχος | Πώς μπαίνουν οι διακομιστές στο GhostVPN |
|---|---|
| `VPN Gate` | ⚡ αυτόματα, ένα κλικ: δωρεάν δημόσιοι διακομιστές |
| `IPSpeed` | ⚡ αυτόματα, ένα κλικ: δωρεάν δημόσιοι διακομιστές |

Πού: **SETTINGS → ADVANCED → 🆓 DARMOWE VPN (free VPN) → UPDATE**. Κάθε προφίλ που κατεβαίνει ελέγχεται πριν αποθηκευτεί.

> ⚠️ Οι δωρεάν δημόσιοι διακομιστές είναι πιο αργοί και τους λειτουργούν άγνωστοι. Για τράπεζες και σημαντικές συνδέσεις χρησιμοποίησε επί πληρωμή VPN.

## 🔐 OpenVPN, WireGuard ή proxy;

| | OpenVPN | WireGuard | Proxy |
|---|---|---|---|
| Κρυπτογράφηση | ✔ AES-256 | ✔ ChaCha20 | ✘ μόνο το HTTPS του ιστότοπου |
| Προστατεύει όλο το σύστημα | ✔ ναι | ✔ ναι | μόνο επιλεγμένες εφαρμογές |
| Ταχύτητα | καλή | πολύ υψηλή | εξαρτάται από τον διακομιστή |
| Σύνδεση | λίγα δευτερόλεπτα | μια στιγμή | αμέσως |
| Kill Switch | ✔ | ✔ | — |
| Ιδανικό για | καθημερινή χρήση, μπλοκαρισμένα δίκτυα | παιχνίδια, streaming | γρήγορη αλλαγή IP στον browser |

Τα στοιχεία σύνδεσης VPN κρυπτογραφούνται από τα Windows (DPAPI) και μένουν στον υπολογιστή σου. Το GhostVPN δεν έχει λογαριασμό, διαφημίσεις ή παρακολούθηση.
